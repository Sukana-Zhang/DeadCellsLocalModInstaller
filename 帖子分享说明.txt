Dead Cells 死亡细胞本地 Mod 安装小工具：自动把创意工坊 Mod 打包为 res1.pak/res2.pak


工具用途
这个工具用于把 Steam 创意工坊下载的 Dead Cells / 死亡细胞 Mod 转成本地资源包加载。

一般创意工坊 Mod 位于：

  Steam\steamapps\workshop\content\588650\<Workshop ID>\res.pak

工具会自动扫描 Steam 库，找到死亡细胞本体目录和创意工坊 Mod，然后重新打包成：

  res1.pak
  res2.pak
  res3.pak

并放入游戏本体目录：

  Steam\steamapps\common\Dead Cells\

原版 res.pak 不会被修改。

工具会从游戏本体 res.pak 的文件头部自动提取 64 位打包密钥，不需要手动填写密钥。游戏更新导致密钥变化时，工具也会优先使用当前本体 res.pak 里的新密钥。


使用方法
1. 先在 Steam 创意工坊订阅并下载你要使用的死亡细胞 Mod。
2. 下载并解压本工具。
3. 双击：

   InstallLocalMods.cmd

4. 选择功能：

   1 = 安装创意工坊 Mod 为本地 Mod
   2 = 移除本地 Mod，工具会先备份 res1.pak/res2.pak 等文件

5. 如果检测到多个 Mod，工具会列出编号和名称。
6. 输入你想安装的顺序，例如：

   1
   1,3,2

7. 工具会按顺序生成：

   第 1 个 Mod -> res1.pak
   第 2 个 Mod -> res2.pak
   第 3 个 Mod -> res3.pak

8. 安装完成后，从 Steam 正常启动游戏。
9. 不要在游戏内的 Workshop / Mod 菜单里再启用同一个 Mod。


多个 Mod 的说明
多个 Mod 同时使用时，加载顺序可能会影响结果。

通常可以理解为：

  res.pak -> res1.pak -> res2.pak -> res3.pak

后面的包可能覆盖前面的包。

如果两个 Mod 修改了同一个资源文件，例如 data.cdb 或同一个 atlas 文件，可能出现以下情况：

  两个 Mod 都正常生效
  后面的 Mod 覆盖前面的 Mod
  部分内容不生效
  游戏报错或崩溃

这类 Mod 冲突工具无法自动完美解决，需要自行调整安装顺序或只安装其中一个。


备份说明
安装前，工具会把游戏目录里已有的本地 Mod 文件移动到工具目录下的备份目录：

  Backups\LocalModBackup-YYYYMMDD-HHMMSS

工具只处理这些文件：

  res1.pak
  res2.pak
  res3.pak
  ...

不会移动或修改原版：

  res.pak

备份不会放在游戏本体目录或创意工坊目录，避免污染别人的游戏文件夹。


卸载方法
再次运行 InstallLocalMods.cmd，选择：

  2

工具会备份并移除游戏目录里的 res1.pak、res2.pak、res3.pak 等本地 Mod 文件。


已知限制
1. 工具只适用于 Steam 版死亡细胞。
2. 需要先通过创意工坊把 Mod 下载到本地。
3. 如果 Mod 之间有资源冲突，工具只能按顺序打包，不能自动合并冲突。
4. 工具会自动从本体 res.pak 提取当前密钥，但如果游戏后续版本彻底修改了 PAK 格式，当前打包方式仍可能失效。
5. 本工具不会修改游戏原版 res.pak，但使用前仍建议自行备份存档。


文件来源与致谢
这个分享包不是从零实现 PAK 解包/打包逻辑。

本工具主要做的是：

  自动查找 Steam 库
  自动查找死亡细胞安装目录
  自动扫描 Workshop Mod
  读取 settings.json 显示 Mod 名称
  让用户选择多个 Mod 的安装顺序
  从游戏本体 res.pak 自动提取 64 位打包密钥
  调用 PAKTool 进行解包和重新打包
  自动把旧的 res1.pak/res2.pak 备份到工具目录
  自动复制新生成的本地 Mod 到游戏目录
