# Security

Please use GitHub's private vulnerability reporting for security issues. Do not post API keys, tokens, save files or personal paths in public issues.

This tool works locally and does not send telemetry or upload game files. Only run mod packages you trust. Dependency checksums are recorded in `dependencies.sha256`; upstream origins and licenses are in `THIRD-PARTY-NOTICES.md`.

Diagnostic TXT exports contain environment details and recent logs. User profile paths, user SIDs and native stamp output are redacted, but custom directory names may remain. Review the TXT before sharing it; no export is uploaded automatically. Do not attach game resources, backups, saves or credentials to reports.
